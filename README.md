# EventSphere

> AI-powered college event management and student engagement platform.

EventSphere is a modern campus event management platform designed to simplify how
students discover, register for, and engage with college events while helping
organizers efficiently create, manage, and analyze events.

## Overview

Managing college events often involves multiple platforms, manual registrations,
scattered announcements, and limited visibility into student participation.

EventSphere brings these activities together into a single platform where
students can discover upcoming events, register for them, receive relevant
information, and track their participation.

Organizers can create and manage events, monitor registrations, communicate
with participants, and analyze event performance.

## Key Features

- Event discovery and browsing
- Student event registration
- Event details and schedules
- Organizer event management
- Student engagement tracking
- Registration management
- Event analytics and insights
- AI-powered event recommendations
- Personalized event discovery
- Secure user authentication
- Role-based access for students and organizers
- Responsive and modern user interface
